## 🔹 Overview

This repository contains a **complete SOC operations lab** simulating enterprise environments with multi-VM setups. It demonstrates **threat detection, incident response, and SOC workflow** in a controlled environment.

**Lab Features:**  
- **Real-time monitoring and alerting** using Splunk SIEM  
- **Windows endpoints** representing enterprise workstations  
- **Kali Linux attacks** simulating malicious activity  
- **End-to-end SOC workflow**: detection → investigation → remediation  
- **Executive-level reporting** of incidents  

---

## 🔹 Lab Objectives

1. Detect and respond to attacks such as brute-force, malware, and network reconnaissance  
2. Map alerts and incidents to the **MITRE ATT&CK framework**  
3. Produce **executive-level incident reports**  
4. Demonstrate **full SOC workflow**: alert triage → investigation → containment → mitigation
